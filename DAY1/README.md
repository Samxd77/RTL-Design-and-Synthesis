## 1. Understanding Simulator, Design, and Testbench

### Simulator
A simulator is a software application used to verify the behavior of digital circuits. It executes the design using different input combinations and displays output responses, allowing engineers to validate functionality before implementation on hardware.

### Design
The design refers to the Verilog HDL description that defines the logic and operation of a digital circuit.

### Testbench
A testbench is a verification module used to stimulate the design with various test cases and monitor whether the generated outputs match expected behavior.

Together, the design and testbench create a complete simulation environment for functional verification.
